# 边城服饰数字展（Border-City Costume Digital Exhibition）

服饰、纹样、称呼与穿着场合的编辑型数字展。系统采用**多来源陈述模型**而非单一权威标签：
每一条解释都是一条带「地区 / 年代 / 具体来源」的独立陈述，同一纹样在不同语境下的
不同含义分条保存、互不合并；舞台复原、历史实物、当代日常为互相独立的展品类型。

## 运行

```bash
npm run seed     # 写入演示数据 data/db.json
npm start        # http://localhost:3000
npm test         # 全部验收测试（node:test）
```

编辑器：`http://localhost:3000/editor.html`（写操作需要编辑身份，见下）。

## 领域模型（见 docs/statements.md）

- **Exhibit 展品**：type ∈ `historical`（历史实物）/ `stage_reconstruction`（舞台复原）/
  `contemporary_daily`（当代日常）；`loan`（借出）只影响现场可见性，不改写历史说明；
  `photoPermission`（拍摄许可）独立控制图片渠道。
- **Statement 陈述**：对纹样/称呼/场合的一条解释，绑定 region、年代范围、具体来源
  （文献/田野采访/馆藏记录），带 confidence、审校状态与争议标记。
  - 相同图案不同语境的解释**绝不合并**（`motifId` 只是图形分组，不代表含义相同）。
  - 来源撤回 → 陈述标记 `retracted`（不物理删除，保留审校痕迹），立即从展示渠道撤回；
  - 只有 `approved` 且未撤回的陈述进入已发布快照，争议可以随审校结论一并发布。
- **Region 地区**：有稳定 `id`；改版称呼时生成新名称版本，旧称保留为曾用名（可检索）。
- **MediaTask 媒体任务**：生成细节图时把原图标注坐标按裁切矩形换算到细节图坐标，
  落在裁切区外的标注标记为 `outside` 而非错误平移。

## 发布模型

编辑批准后，搜索索引与展品详情**统一原子换版**（publication 快照），旧索引立即停止
展示受限/撤回/未批准的解释。审批前的草稿只在编辑器中可见。

## 权限

- 写 API 需要请求头 `X-Editor: <token>`，默认演示 token 为 `editor-token`
  （`BC_EDITOR_TOKEN` 可覆盖）。
- 图片渠道（图像文件/带标注图像）单独受拍摄许可控制；无图片时仍展示已授权文字。

## 可访问性与离线

- 细节查看全部支持键盘（Tab 聚焦、Enter 打开、Esc 关闭、方向键切换）。
- 已收藏页面注册 Service Worker 离线可用；离线时展示已缓存文字，无许可的图片永不缓存。

## 验收场景

见 `test/`：地区称呼改版、翻译缺失回退、裁切标注偏移、来源撤回、已收藏页离线回归、
借出可见性、拍摄许可渠道隔离、批准原子换版、同纹异义不合并、范围匹配筛选、
独立类型筛选、键盘导航。
